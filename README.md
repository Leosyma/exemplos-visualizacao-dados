# 📊 Data Visualization Examples

This repository showcases a comprehensive collection of Python notebooks exploring various data visualization techniques using libraries such as Matplotlib, Seaborn, and Plotly. These examples are designed to demonstrate the power of visual storytelling in data science and provide practical guidance on how to apply different types of plots to understand and communicate data effectively.

## 🔍 Project Structure

### 1. Distribution Plots (`1-plots-de-distribuicoes.ipynb`)
- Demonstrates how to visualize the distribution of variables using histograms, KDE plots, and rug plots with Seaborn.
- Useful for identifying skewness, modality, and outliers in data.

### 2. Categorical Plots (`2-plots-categoricos.ipynb`)
- Explores visualization of categorical variables using bar plots, count plots, box plots, violin plots, and swarm plots.
- Aids in comparing categories and detecting patterns or imbalances.

### 3. Regression Plots (`3-plots-de-regressoes.ipynb`)
- Shows how to create scatter plots and regression lines using `regplot` and `lmplot`.
- Highlights relationships between numerical variables and trends.

### 4. Matrix Plots (`4-plots-matriciais.ipynb`)
- Includes heatmaps and correlation matrices to reveal inter-variable relationships.
- Valuable for multivariate analysis and feature selection.

### 5. Styles and Colors (`5-estilos-e-cores.ipynb`)
- Illustrates how to customize visualizations using Seaborn and Matplotlib themes and color palettes.
- Enhances plot readability and presentation.

### 6. PairGrid (`6-pairgrid.ipynb`)
- Demonstrates how to use Seaborn’s `PairGrid` for advanced multi-plot layouts.
- Excellent for pairwise variable comparison in a dataset.

### 7. Plotly Examples (`exemplos-plotly.ipynb`)
- Introduces interactive visualizations with Plotly including scatter, bar, and line charts.
- Enables dynamic exploration and better user interaction.

### 8. Matplotlib Summary (`resumo-matplotlib.ipynb`)
- Offers a concise review of Matplotlib’s core plotting capabilities.
- Good reference for customizing and combining plot types.

## 📦 Libraries Used

- Plotly

## 🚀 How to Use
1. Clone this repository.
2. Open the notebooks in Jupyter or Google Colab.
3. Run each cell to view the visualizations and experiment with parameters.
